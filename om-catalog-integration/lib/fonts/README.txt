Fonts for the Insights PDF report, embedded (as subsets) in the reports it builds.

Manrope (Regular 400, SemiBold 600, Bold 700): static instances of Manrope[wght].ttf,
Copyright 2018 The Manrope Project Authors (https://github.com/googlefonts/manrope).
Fraunces 72pt (Regular 400, Medium 500; SOFT 0, WONK 0): static instances of
Fraunces[SOFT,WONK,opsz,wght].ttf, Copyright 2018 The Fraunces Project Authors
(https://github.com/undercasetype/Fraunces).

Both are licensed under the SIL Open Font License 1.1 (OFL-Manrope.txt, OFL-Fraunces.txt) and
declare no Reserved Font Names. The instances keep Latin, Latin-1, Latin Extended-A and common
punctuation only; they were made with fontTools from the Google Fonts releases.
